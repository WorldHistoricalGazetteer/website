Gazetteer Workbench

WHG offers three pathways for using its tools and services
to augment and publish historical place data

1 Datasets (Upload Structured Place Data)

Use this pathway if you have a spreadsheet, CSV, or GeoJSON containing place records—such as historical towns, administrative units, archaeological sites, mills, villages, etc. This is for contributors who want to publish or share raw place data with WHG so it can be reconciled, mapped, and linked to other datasets.

2 Dataset Collections (Combine Multiple Datasets)

Use this pathway if you want to integrate several published datasets into a single collection for comparison or analysis. This is ideal for researchers combining different sources (e.g., colonial gazetteers + archaeological sites + modern administrative data) to see overlaps or differences across datasets.

See Pathway 1—Dataset Collections begin with individual datasets!

3 Place Collections (Curate Places for Teaching or Thematic Storytelling)

Use this pathway if you want to select and curate places manually to tell a story, build a historical narrative, or design a teaching assignment. This is for creating collections such as “Industrial Bombay,” “Silk Road Cities,” or “Women in the Freedom Movement.” Place Collections are not data uploads—they are curated selections meant for interpretation, pedagogy, or thematic exploration.
