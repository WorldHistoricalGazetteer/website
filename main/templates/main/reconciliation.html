Turn a list of place names into located, dated, standardised places — matched to the World Historical Gazetteer, cleaned up, and ready to map or share, entirely in your browser. Works for a single place or thousands of rows.

Sends a place-name query per row (with a country hint where available) to WHG's /reconcile service — just the name, never your full rows. Best matches appear below; per-candidate review comes in the next phase.

or the name matches exactly — so review can focus on the rest.

Place names are reconciled individually — identical names are not merged, so each row can be matched to a different place. Administrative levels (county, region…) are merged: identical values in the same parent are reconciled once and applied to every row.

    Resolve changes

    A teammate changed some of the same items while you were editing. Choose which version to keep for each. Everything else was merged automatically.

    Source gazetteers

    Choose how the source gazetteers (namespaces) affect reconciliation, then tick the sources below. Your choice is saved and persists across page loads. Only selected filters the query, so it takes effect on the next reconcile run; Prioritise selected re-orders the existing candidates immediately. Hover a source for its description.

    Dataset-wide scope

    Narrow the whole dataset to a place, period, or kind of feature before matching — every row's query is constrained the same way, which sharpens disambiguation. Leave a section blank to not constrain it. Your choice is saved with the project. Changing it resets existing matches so they can be reconciled again under the new scope.
