The same place can be written in many alphabets. To match those spellings to each other, WHG turns each name into sounds. It does that with a list of rules for each language: this letter makes this sound.

Some of those lists are good. Some are missing letters, or give the wrong sound. Where a list is poor, WHG cannot match names in that alphabet at all.

We cannot fix the lists ourselves. We need people who read the language. Each task is one letter and takes a few seconds.
