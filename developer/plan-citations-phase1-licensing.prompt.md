# Phase 1 — `licensing` app + `License` model

**Parent design:** `developer/plan-citations-licences-credit.prompt.md` (§3.1, §6 Phase 1, §7 leapfrog).
**Goal:** introduce a single, truthful, reusable licence vocabulary and attach it to `Dataset` and `Collection`, with admin + a shared render partial. **No CRediT, no API, no registry/`api` migration** in this phase.
**Branch:** cut `citations` from **`main`**. This phase touches only parity apps (`datasets`, `collection`) + a new app, so it merges to `main` with zero migration collisions.

## 3. `License` model (`licensing/models.py`)

```python
from django.db import models

class License(models.Model):
    spdx_id   = models.CharField(max_length=64, unique=True,
                    help_text="SPDX identifier, e.g. 'CC-BY-4.0'. Use a 'custom-*' id for non-SPDX terms.")
    label     = models.CharField(max_length=128)
    url       = models.URLField(blank=True,
                    help_text="Canonical licence deed / terms URL.")
    spdx_uri  = models.URLField(default="https://spdx.org/licenses/")
    permits_commercial   = models.BooleanField(default=True)
    share_alike          = models.BooleanField(default=False)
    attribution_required = models.BooleanField(default=True)
    custom    = models.BooleanField(default=False,
                    help_text="True for bespoke / non-SPDX terms; pair with rights_statement on the object.")
    notes     = models.TextField(blank=True)

    class Meta:
        ordering = ["spdx_id"]

    def __str__(self):
        return self.spdx_id

    @property
    def spdx_url(self):
        """Link to the SPDX page, or None for custom licences."""
        return None if self.custom else f"{self.spdx_uri.rstrip('/')}/{self.spdx_id}.html"
```

Design notes:
- `blank=True` (not `null=True`) on text fields per the codebase's mixed style; `unique=True` on `spdx_id` is the natural key the inventory endpoint (Phase 4) will resolve against.
- No `objects` customisation needed; lookups by `spdx_id`.

## 7. Rendering — shared badge partial

`licensing/templates/licensing/_license_badge.html`:
```django
{% if license %}
  <a href="{{ license.url|default:license.spdx_url }}" target="_blank" rel="noopener"
     class="badge bg-light text-dark border" title="{{ license.label }}">
    {{ license.spdx_id }}
  </a>
  {% if rights_statement %}<div class="small text-muted">{{ rights_statement }}</div>{% endif %}
{% endif %}
```
Wire-in points (Phase 1):
1. **`datasets/templates/datasets/ds_metadata.html:278-282`** — replace the hard-coded `<a href=".../by/4.0/">CC BY-NC 4.0</a>` (the label/href-mismatch bug) with `{% include 'licensing/_license_badge.html' with license=object.license rights_statement=object.rights_statement %}`, falling back to the WHG overlay text when `object.license` is null.
2. **Collection metadata template** — same include.
3. Leave DOI/download envelopes untouched this phase (they still emit the existing constant; rewired in Phase 2/3 once data flows).

> The badge currently shows the **source** licence on the object. The WHG overlay is rendered as separate boilerplate (existing `licensing_info.html` / `license.html` stay as the platform statement) — keeping the two visually distinct per decision 2.
