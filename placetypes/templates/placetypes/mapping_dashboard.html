How to use this dashboard
  • Each tab lists place-type values from a source vocabulary (GeoNames feature codes, Wikidata Q-items, OSM/OHM tags).
  • Count shows how many records in the WHG places index use that type.
  • Click Map on an unmapped row to search for and assign an AAT concept; click Remove to clear one.
  • Use the filter box and Hide matched toggle to focus on unmapped types.
  • Rows are sorted by count so the highest-impact types appear first.

Goal: once each vocabulary reaches 95 % coverage by record count, the complete mapping table will be published as an open dataset on Zenodo for reuse by other projects.
