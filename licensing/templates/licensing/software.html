The World Historical Gazetteer is built on open-source software written by others. This page lists every third-party package the platform actually deploys, with the licence each is published under. It is generated from the running system rather than from our source repository, so it reflects what is genuinely in service on the date shown.

WHG's own source code is released under the BSD 3-Clause Licence, and the data carries per-source terms described on the licences page. The authoritative record of any package below is that project's own repository, linked from its name.

Why this is generated, not written. A dependency list maintained by hand goes stale quietly, and a stale licence statement is worse than a general one — a general statement is merely unhelpful, whereas a stale specific one is a positive misstatement. This page is rebuilt by a single command that reads the deployed environment directly; the audit date above is therefore true by construction.
