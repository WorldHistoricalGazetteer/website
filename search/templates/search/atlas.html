WHG Atlas

The WHG Atlas is a visualisation tool for the World Historical Gazetteer — {{ index_places }} place records and {{ index_toponyms }} distinct toponyms, combining scholarly curated gazetteers with large-scale public gazetteers including GeoNames and Wikidata. At this scale, spatial and temporal scoping of searches is highly desirable.

Start in Areas mode to select geographic regions, then switch to Places to search for place names within them. Use Regions, Gazetteers, and Categories to refine your view.

Regions

Select a source for geographic regions such as empires, polities, kingdoms, and administrative territories. Regions selected from the map act as spatial constraints for subsequent toponym searches.

Gazetteers

Choose which gazetteers to include in your search. Checked gazetteers contribute place records to the results; uncheck any you wish to exclude.

Select a single gazetteer to browse it in Explorer view — its records become the primary content, with clustering, comparison, and link/distinct affordances scoped to that gazetteer.

Coverage filtering is not yet implemented — the switch will activate once gazetteer-level h3_coverage and temporal_extent arrive via the extended /suggest API (Master Plan Phase 2).
While exploring, signed-in users can add Attestations to any place. When exploring one of your own gazetteers, you can additionally add places, edit data and metadata, and adjust the clustering — equivalent to the reconciliation / accessioning workflow in v3.2.
